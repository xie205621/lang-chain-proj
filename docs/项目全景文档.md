# 小智数码产品导购 — 项目全景文档

---

## 一、项目概览

| 项目 | 说明 |
|------|------|
| **项目名** | lang-chain-proj（小智数码产品导购） |
| **定位** | 基于 AI 大模型的智能数码产品导购助手 |
| **主营品类** | 手机📱、笔记本💻、耳机🎧、键盘⌨️、鼠标🖱️ |
| **技术栈** | Spring Boot 3.2 + LangChain4j + MyBatis-Plus + MongoDB + MySQL |
| **AI 模型** | 阿里云百炼 DashScope（qwen-plus 流式） |
| **前端** | 纯 HTML/CSS/JS 单页聊天界面（内嵌于 Spring Boot） |
| **端口** | 8080 |

## 二、六个业务模块

### 模块一：智能商品搜索 🔍

| 项目 | 说明 |
|------|------|
| **用户说** | "我想买一副300元以内的蓝牙耳机" |
| **技术原理** | AI 理解意图 → 调用 `searchProduct` 工具 → 查 MySQL `product` 表 |
| **数据来源** | MySQL 数据库真实数据，非 AI 编造 |
| **搜索维度** | 关键词（名称/分类/品牌/描述模糊匹配）、品类、品牌、价格范围 |
| **排序** | 按销量降序 |
| **核心文件** | `ShopTools.searchProduct()` → `ProductMapper.searchByKeyword()` / `searchByFilter()` |

### 模块二：智能推荐 🎯

| 项目 | 说明 |
|------|------|
| **用户说** | "我预算5000以内，想买一台适合学习办公的笔记本" |
| **技术原理** | AI 调用 `recommendProduct` → 综合评分×销量排序 → Top3 |
| **推荐理由** | 自动生成：高评分→"口碑极佳"、高销量→"热销爆款"、综合指数→"性价比突出" |
| **核心文件** | `ShopTools.recommendProduct()` → `ProductMapper.getTopRecommended()` / `recommendByCategory()` |
| **理由生成** | `ProductServiceImpl.generateRecommendReason()` |

### 模块三：多平台比价 📊

| 项目 | 说明 |
|------|------|
| **用户说** | "帮我比比iPhone 15哪个平台便宜" |
| **技术原理** | AI 调用 `comparePrice` → 按商品名查所有平台 → 表格对比 |
| **比价平台** | 淘宝、京东、拼多多 |
| **最低价** | 自动标注最低价平台并给出购买建议 |
| **核心文件** | `ShopTools.comparePrice()` → `ProductMapper.compareByProductName()` |

### 模块四：一键下单 🛒

| 项目 | 说明 |
|------|------|
| **用户说** | "我要买第一个商品，数量1，地址是郑州" |
| **技术原理** | AI 确认完整信息后调用 `createOrder` → 写入 MySQL `orders` 表 |
| **必填信息** | 用户ID、商品ID、商品名、价格、数量、地址、电话 |
| **缺信息处理** | 主动追问，不自作主张猜测 |
| **订单号** | `yyyyMMddHHmmss` + 4位随机数 |
| **核心文件** | `ShopTools.createOrder()` → `OrderServiceImpl.createOrder()` |

### 模块五：订单管理 📋

| 项目 | 说明 |
|------|------|
| **查订单** | 按用户ID查全部 或 按订单号精确查 |
| **取消订单** | 仅允许取消"待付款""已付款"状态；已发货/已完成不可取消 |
| **二次确认** | 取消前 Tool 描述要求 AI 二次确认 |
| **核心文件** | `ShopTools.queryOrder()` / `cancelOrder()` → `OrderMapper` |

### 模块六：售后问答 💬

| 项目 | 说明 |
|------|------|
| **用户说** | "蓝牙耳机买回来不喜欢，可以退吗？" |
| **技术原理** | RAG（检索增强生成）：从知识库检索相关文档 → AI 结合上下文生成回答 |
| **知识库** | 3 篇文档：`商品指南.md`、`售后政策.md`、`促销活动.md` |
| **向量化** | 使用内置 Embedding 模型（bge-small-en-v15-q）→ 内存向量存储 |
| **检索方式** | `EmbeddingStoreContentRetriever` 自动语义检索 |
| **核心文件** | `ShopConfig.contentRetrieverShop()` + `ShopTools.askAfterSale()` |

### 4.3 LangChain4j 工作原理

```
用户消息
    │
    ▼
┌──────────────────────────────────────────┐
│  ShopAgent.chat(memoryId, message)        │
│                                          │
│  1. 从 chatMemoryProvider 加载历史对话      │
│  2. 组装 system prompt + 历史消息 + 用户消息  │
│  3. 发给 qwen-plus 大模型                  │
│  4. 模型决定：直接回复 OR 调用某个 Tool      │
│                                          │
│  ┌── 如果调用 Tool ──────────────────┐    │
│  │ 5a. 执行 ShopTools 对应方法        │    │
│  │ 5b. 把 Tool 返回值发给模型          │    │
│  │ 5c. 模型结合结果生成回复             │    │
│  └──────────────────────────────────┘    │
│                                          │
│  6. 保存对话到 chatMemoryProvider          │
│  7. Flux<String> 逐字流式返回              │
└──────────────────────────────────────────┘
```

## 六、RAG 知识库

### 6.1 工作原理

```
用户问："蓝牙耳机可以退吗？"
         │
         ▼
┌──────────────────────────────────┐
│  1. Embedding 模型将问题向量化     │
│  2. 与知识库文档向量做语义相似度匹配  │
│  3. 召回最相关的文档片段            │
│  4. 将片段作为上下文拼入 system prompt│
│  5. AI 基于上下文生成准确回答        │
└──────────────────────────────────┘
```

### 6.2 知识库文件

| 文件 | 内容 |
|------|------|
| `knowledgenew/商品指南.md` | 蓝牙耳机/笔记本/手机/键盘鼠标选购要点 |
| `knowledgenew/售后政策.md` | 七天无理由退货、保修政策、退款规则、客服联系 |
| `knowledgenew/促销活动.md` | 新人专享、限时折扣、满减、会员权益、支付优惠、物流 |

### 6.3 流程代码

```java
// ShopConfig.java
@Bean
ContentRetriever contentRetrieverShop() {
    // 1. 加载知识库文档
    Document doc1 = FileSystemDocumentLoader.loadDocument("knowledgenew/商品指南.md");
    Document doc2 = FileSystemDocumentLoader.loadDocument("knowledgenew/售后政策.md");
    Document doc3 = FileSystemDocumentLoader.loadDocument("knowledgenew/促销活动.md");

    // 2. 创建内存向量存储
    InMemoryEmbeddingStore<TextSegment> embeddingStore = new InMemoryEmbeddingStore<>();

    // 3. 文档分割 + 向量化 + 存入向量库（一行搞定）
    EmbeddingStoreIngestor.ingest(documents, embeddingStore);

    // 4. 返回检索器
    return EmbeddingStoreContentRetriever.from(embeddingStore);
}
```

### 6.4 Embedding 模型

使用 **BGE-small-en-v15-q**（本地 ONNX 模型），无需联网调用：
```xml
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-embeddings-bge-small-en-v15-q</artifactId>
</dependency>
```

## 八、前端设计

### 8.1 技术选型

| 项 | 选择 | 理由 |
|-----|------|------|
| 框架 | 无框架，纯 HTML/CSS/JS | 零依赖，Spring Boot 直接托管 |

| 样式 | CSS 变量 + Grid/Flexbox | 仿 ChatGPT 风格 |
| Markdown | 手写简易解析器 | 支持粗体、表格、换行 |

### 8.3 流式数据处理

```javascript
// 核心流程
fetch('/shop/chat', { method: 'POST', body: JSON.stringify(payload) })
  → response.body.getReader()   // 获取流式读取器
  → 自动检测 SSE 或纯文本格式
  → 逐块解码 → 实时更新气泡内容
  → 完成后去除打字光标，保存到 localStorage
```

### 8.4 格式兼容

| 响应格式 | 检测方式 | 处理方式 |
|----------|----------|----------|
| SSE (`data:xxx\n\n`) | 首行以 `data:` 开头 | 解析 `data:` 行 |
| 纯文本流 | 首行不以 `data:` 开头 | 直接拼接 |

## 十一、系统提示词（System Prompt）

文件位置：`src/main/resources/shop-prompt-template.txt`

核心约束规则：

| 规则 | 内容 |
|------|------|
| **品类限制** | 只经营手机、笔记本、耳机、键盘、鼠标五类，问其他品类直接拒绝 |
| **下单确认** | 必须确认商品名/价格/数量/地址/电话全部信息后才下单 |
| **取消确认** | 取消前二次确认 |
| **推荐理由** | 每个推荐必须附带理由 |
| **安全** | 不索要支付密码、银行卡号 |
